GitHub Deployment for "React.js" Project:

Step-1:
  Create a Public Repository in your GitHub Account.
    ex: Doctor-Appointment

Step-2:
   Open Your React.js project with "Vscode"
   Initialize git and execute below commands in terminal

                                                                                                                                                                          
   git init                                                                                       
   git status                                                                                     
   git add .                                                                                                                                                                                 
   git status                                                                                                                                                                                
   git commit -m "First Commit"                                                                                                                                                                                                                                                   
   git branch -M main                                                                             
   git remote add origin https://github.com/praveen-new-ac/Doctor-Appointment.git                 
   git push -u origin main                                                                        
   
The Project is Successfully pushed to Remote GitHub Repository

Step-3:
  Go to GitHub
    Settings-->Pages
 
Under "Build and deployment"
    Choose Source:  Deploy from a branch

    Branch: Main
      save

Step-4:
   Click on "Actions" it shows "pages build and deployment".

  under deploy click on Generated "URL"

  it shows "ReadME.md" information

Under Settings-->Pages    Cancel publish site
Under "Build and deployment"
    Choose Source:  GitHub Actions
    Under Actions--->General 
    choose: Workflow permissions: Read and write permissions
      save

Step-5:
  Now deploy using below process.

   Open Project in vscode create the following folder structure.

       .guthub/workflows
     
     and create "cicd.yml" file and paste below code.

   
   name: Deploy to GitHub Pages

on: 
  push:
    branches: [ main ]

permissions:
  contents: read  
  pages: write      
  id-token: write   
jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Source  
        uses: actions/checkout@v4
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
            node-version: 20
      - name: Install Dependencies
        run: npm ci
      - name: Build Project
        run: npm run build      
      - name: Upload artifacts
        uses: actions/upload-pages-artifact@v3   
        with:
           name: 'github-pages'
           path: build
      - name: Deploy to GitHub Pages
        uses: actions/deploy-pages@v4
        with: 
          token: ${{ secrets.GITHUB_TOKEN }}
          artifact_name: 'github-pages'


save it and push the above file into GitHub Repo

  
UInder package.json add below line:

 "homepage": "https://praveen-new-ac.github.io/Doctor-Appointment/"


it shows new deploy
